I18N_MISS_MAX_UNIQUE唯一串数量上限：达到后停止整个扫描，避免继续为正则/分词分配临时 list。
I18N_MISS_MAX_LENGTH单条记录最大长度：更长的多为玩家书写/超长拼接，截断意义不大，直接跳过。
/proc/lang_log_miss记录一条 miss（去重计数；首次与 10/100/1000 次时写日志行）。
/proc/lang_i18n_extract_runs从一段（可能含 HTML/中英混排的）文本提取「连续拉丁词 run」列表。纯函数，单测覆盖。 run 判定：≥3 个拉丁词，或恰 2 词且至少一词以小写字母开头；纯数字/标点 token 允许 出现在 run 内部（不计词数、不留边缘）；含 CJK 或其它非拉丁字符的 token 打断 run。
/proc/lang_i18n_token_kindtoken 分类：拉丁词（可含数字/'/-/尾随标点）/ 中性（纯数字标点）/ 断点（CJK、其它字符、空）。
/proc/lang_i18n_flush_run结算一个 run：去尾部中性 token，按词数门槛决定是否收进 runs。
/proc/lang_log_miss_scanfallback 层出口扫描：对（已过模板引擎 + AC 的）文本提取残留英文 run 并记录。
